>[!idea] Idea
>The transfer function describes how the output of an LTI system reacts to the input
>$$
>G(s) = \frac{Y(s)}{U(s)}
>$$
>Thus, transfer functions are **Input-Output Models**.

>[!pro] PRO
>- **Simple** analysis, e.g., stability

>[!con] CON
>- Only for **LTI systems**
>- Generally only **SISO**
